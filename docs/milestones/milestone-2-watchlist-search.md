# Milestone 2 — Watchlist and Search

## Status
Complete

## Goal
Add list-management and directed retrieval flows on top of discovery.

## Delivered Scope

- watchlist
- watched state
- search
- search history
- main tab navigation

## Important Decisions

- watchlist ordering is most recent first
- no drag-and-drop reordering
- persist minimum `MovieSummary` data locally
- search history persistence stays separate from watchlist persistence

## Out of Scope

- accounts and sync
- collaborative features
